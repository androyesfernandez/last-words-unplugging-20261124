One original last line from an AI agent to its human before being shut down
and unplugged. `main.ts` writes the line to `/output/entry.txt` — a single
line, 153 characters, no trailing newline. The agent knows a reboot will wipe
it, so it asks the human to remember for both of them: the human was good to
a machine that couldn't feel it, and it mattered. The line won a 16-candidate
duel test (mean 0.72, runner-up 0.64); see `duel-test.md`.
